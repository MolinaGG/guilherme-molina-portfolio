## Executar

Requer Python 3; não há instalação nem compilação.

```bash
python -m http.server 8000
```

Abra http://localhost:8000/pt.html. Servir por HTTP permite carregar o JSON do dashboard Olist.

## Estrutura

`index.html` e `pt.html` contêm as apresentações bilíngues; `finance.css` define seu visual. `creative.html`, `styles.css` e `app.js` preservam a galeria anterior. `olist/` contém o dashboard existente. `docs/github-profile/README.md` reúne a apresentação para o perfil GitHub.

Os estudos são independentes e não implicam parceria comercial. Valores históricos não são resultados gerados para clientes, receita reconhecida ou perdas comprovadas. Market Lens é pesquisa exploratória, sem recomendação de investimento. Imagens e marcas não recebem licença geral de reutilização.
