Pergunta de negócio

Quais regiões, categorias e fornecedores merecem investigação ao acompanhar o desempenho das entregas e o valor dos pedidos?

Como foi estruturado

Scripts Python reconstroem os dados do dashboard e os snapshots do Power BI a partir dos CSVs originais. O pipeline MySQL histórico permanece como referência separada. Os indicadores distinguem valores por item de entregas e avaliações por pedido.

O que o estudo mostra

A base documentada reúne 98.666 pedidos com itens. Entre 96.470 entregas com datas válidas, 6.534 chegaram atrasadas: 93,2269% foram pontuais. São observações históricas da base, não melhorias entregues a um cliente.

Decisão que pode apoiar

Usar as visões regionais e de fornecedores para priorizar investigações. Conferir o número de pedidos e o denominador de entregas válidas antes de comparar taxas; amostras pequenas não devem ter o mesmo peso de amostras grandes.

Limites de interpretação

Valor dos produtos não é receita reconhecida nem lucro. Valor associado a atraso ou cancelamento não comprova perda financeira. Os gráficos web respondem aos filtros; algumas visões agregadas do Power BI são snapshots do período completo.

Pergunta de pesquisa

Como os resultados mudam quando incorporamos os cupons a uma análise de retorno de preço?

Como foi estruturado

Uma API Python e uma interface React/TypeScript conectam dados públicos com fontes documentadas a cálculos de retorno, regressões OLS e validação temporal fora da amostra. A demonstração usa snapshots congelados para permitir reprodução.

O que o estudo mostra

A interface compara retorno de preço e retorno com cupons, exibindo coeficientes, intervalos de confiança de 95%, R² e erro fora da amostra. As escolhas do modelo podem ser inspecionadas, em vez de aparecerem como uma pontuação sem explicação.

Decisão que pode apoiar

Comparar as duas definições de retorno na mesma amostra e examinar a incerteza do modelo antes de interpretar a exposição a fatores de mercado. Origem dos dados e alinhamento temporal fazem parte da análise.

Limites de interpretação

Pesquisa histórica exploratória, sem recomendação de investimento. Movimentos após divulgações são associações temporais, não prova de causalidade. A análise de ações usa CSVs locais; cotações de ações não são redistribuídas na demonstração pública.
