## How I approach analytical work

- Start with the business question and the appropriate unit of analysis.
- Make sources, transformations and metric definitions traceable.
- Validate totals, denominators and time alignment before interpreting results.
- Explain what the evidence supports and what remains uncertain.

Software development and automation support this work. Web and visual projects are available in the [complementary portfolio](https://guilherme-molina-portfolio.guilhermemolinasolan.chatgpt.site/creative.html).
